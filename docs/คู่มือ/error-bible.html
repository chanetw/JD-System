⚠️ Error Code & วิธีแก้ไข

รวมข้อผิดพลาดที่พบบ่อยในระบบ พร้อมสาเหตุและวิธีแก้ไขเฉพาะเจาะจง

ข้อผิดพลาดจากการกระทำงาน

Error Code ข้อความ สาเหตุ วิธีแก้
409 ไม่สามารถดำเนินการได้ สถานะงานเปลี่ยนไปแล้ว หรือมีคนอื่นทำก่อน รีเฟรชหน้า แล้วลองใหม่
403 ไม่มีสิทธิ์ดำเนินการ บทบาทของคุณไม่มีสิทธิ์ทำรายการนี้ ตรวจสอบบทบาท หรือติดต่อแอดมิน
400 ข้อมูลไม่ถูกต้อง กรอกข้อมูลไม่ครบ หรือรูปแบบไม่ถูกต้อง ตรวจสอบฟอร์มให้ครบถ้วน
404 ไม่พบงาน งานถูกลบ หรือไม่มีสิทธิ์เข้าถึง ตรวจสอบ DJ-ID หรือติดต่อแอดมิน
500 เกิดข้อผิดพลาดภายในระบบ ปัญหาที่เซิร์ฟเวอร์ รอสักครู่แล้วลองใหม่ หรือแจ้งแอดมิน

ข้อผิดพลาดเฉพาะทาง

❌ "ไม่สามารถปฏิเสธงานได้"

สาเหตุ: สถานะงานไม่อยู่ในช่วงที่อนุญาตให้ปฏิเสธได้

วิธีแก้:

  • ตรวจสอบสถานะปัจจุบันของงาน
  • ผู้รับงานสามารถปฏิเสธได้เฉพาะ assigned และ in_progress
  • ผู้อนุมัติสามารถปฏิเสธได้เฉพาะ pending_approval
  • หากสถานะเป็น completed หรือ rejected จะไม่สามารถปฏิเสธได้
❌ "ไม่สามารถอนุมัติงานได้"

สาเหตุ: คุณไม่ใช่ผู้อนุมัติในเส้นทางการอนุมัติของงานนี้

วิธีแก้:

  • ตรวจสอบว่าคุณอยู่ในเส้นทางการอนุมัติของประเภทงานนี้
  • ติดต่อแอดมินให้เพิ่มคุณเข้าเส้นทางการอนุมัติ
  • หากเป็นงานเก่า อาจถูกมอบหมายให้ผู้อนุมัติคนอื่น
❌ "ไฟล์ใหญ่เกินไป"

สาเหตุ: ไฟล์ที่อัปโหลดมีขนาดเกิน 10 MB

วิธีแก้:

  • บีบอัดไฟล์ก่อนอัปโหลด (ZIP, ลดความละเอียดรูป)
  • แบ่งไฟล์เป็นหลายชิ้น
  • ใช้ลิงก์ภายนอกแทน (Google Drive, Dropbox)
❌ "เซสชันหมดอายุ"

สาเหตุ: Token หมดอายุ หรือไม่ได้ใช้งานนานเกินไป

วิธีแก้:

  • รีเฟรชหน้าเว็บ (F5)
  • ออกจากระบบแล้วเข้าใหม่
  • หากยังไม่ได้ ล้างแคชเบราว์เซอร์ (Ctrl+Shift+R)
