🟢 Flow 4: เริ่มงาน

ผู้รับงาน (Assignee) เริ่มทำงานอย่างเป็นทางการ โดยเปลี่ยน status เป็น "in_progress"

📊 Swimlane Diagram

sequenceDiagram actor E as Assignee participant UI as UI System participant DB as Database participant Notify as Notification E->>UI: เข้า Dashboard "My Jobs" UI->>DB: ดึงรายการ jobs ที่ assigned DB-->>UI: แสดง "assigned" status jobs E->>UI: เลือก job ที่ต้องการเริ่ม UI-->>E: แสดง Job Detail + "Start Work" button E->>UI: กดปุ่ม "Start Work" UI->>DB: update status = "in_progress" UI->>DB: บันทึก start_at timestamp UI->>Notify: ส่งแจ้งเตือน Requester/Team Notify-->>Notify: "Job Started: [Title]" DB-->>UI: Activity log: "Started by [Assignee]" UI-->>E: แสดงข้อความสำเร็จ UI-->>E: redirect ไปยัง Job Detail (in_progress view)

📋 รายละเอียด Flow

1

เข้าถึง "My Jobs" Dashboard

  • Assignee เข้าสู่ระบบด้วย credentials
  • ระบบ redirect ไปยัง "My Jobs" หรือ "Assignee Dashboard"
  • แสดง 3 tabs:
    • Assigned (New): jobs ที่กำหนด แต่ยังไม่ start
    • In Progress: jobs กำลังทำ
    • Completed: jobs เสร็จแล้ว
2

เลือก Job ที่ต้องการเริ่ม

  • Assignee ดูรายการ jobs ใน "Assigned" tab
  • แต่ละ job card แสดง:
    • Job title, type, brief preview
    • Assigned at, Due date (SLA)
    • Status badge: "assigned" (yellow)
    • "View Details" หรือ "Start Work" button
  • Click job card เพื่อเปิด Job Detail
3

ดู Job Detail ก่อนเริ่ม

  • Job Detail page แสดง full information:
    • Brief text + external brief link
    • Input files (reference designs, documents)
    • Approval history (who approved, when)
    • Comments (notes from requester/approver)
    • SLA deadline + countdown timer
  • Assignee ตรวจสอบข้อมูลก่อนเริ่ม
  • สามารถ post question ใน comments ถ้ามีข้อสงสัย
4

เริ่มงาน

  • Assignee กดปุ่ม "Start Work" (หรือ "Begin Job")
  • ระบบอาจสร้าง confirmation dialog:
    • "Confirm you want to start this job?"
    • "Due date: [date] ([X] days remaining)"
  • Confirm → ระบบประมวลผล
5

ระบบประมวลผล

  • Update Job Status: assigned → in_progress
  • บันทึก Timestamp: start_at = current time
  • สร้าง Activity Log: "Started by [Assignee Name]" + time
  • ส่งแจ้งเตือน:
    • Requester: "Your job [Title] is now in progress"
    • Other assignees (ถ้า multi-assigned): notification อัปเดต
  • Redirect: ไปยัง Job Detail view in_progress

✅ Success Criteria

  • ✓ Job status เปลี่ยนเป็น "in_progress"
  • ✓ start_at timestamp บันทึก
  • ✓ Assignee มองเห็น job ใน "In Progress" tab
  • ✓ Notification ส่งไปยัง relevant parties
  • ✓ SLA timer เปิดอยู่แล้ว

⚠️ Multi-Assignee Start

  • ถ้า job assigned ให้หลาย assignees
  • แต่ละคนสามารถ start เอกเทศได้
  • Job status เปลี่ยนเป็น in_progress ทั้งหมดหลังจาก assignee คนแรก start
  • Activity log บันทึกว่าคนไหน start เมื่อไร
