บทบาทผู้ใช้งาน

ระบบแบ่งผู้ใช้ออกเป็น 4 บทบาทหลัก แต่ละบทบาทมีสิทธิ์และหน้าที่ต่างกัน

📝
ผู้สั่งงาน (Requester)
สร้างงาน แนบไฟล์ ติดตามสถานะ และรับผลงานที่เสร็จสิ้น
✅
ผู้อนุมัติ (Approver)
พิจารณาอนุมัติ/ปฏิเสธงาน ตรวจสอบรายละเอียด และกำหนดผู้รับงาน
🎨
ผู้รับงาน (Assignee)
รับงานที่ได้รับมอบหมาย ดำเนินการ อัปโหลดผลงาน และอัปเดตความคืบหน้า
⚙️
ผู้ดูแลระบบ (Admin)
จัดการประเภทงาน เส้นทางการอนุมัติ วันหยุด และการตั้งค่าระบบ

เส้นทางการทำงานของงาน (Job Workflow)

งานแต่ละชิ้นจะผ่านขั้นตอนต่างๆ ตามลำดับดังนี้

แนะนำสำหรับผู้เริ่มต้น: Happy Path Session

ดูเส้นทางเดียวแบบครบจบ ตั้งแต่เปิดงานจนปิดงาน: สร้างงาน -> อนุมัติ -> มอบหมาย -> ทำงาน -> ส่ง Draft -> ผู้สั่งงานอนุมัติ Draft -> ส่ง Final -> ปิดงาน

เปิดหน้า Happy Path
draft → submitted → pending_approval → approved → assigned → in_progress → completed

งานอาจถูก rejected ได้ในหลายจุดของเส้นทาง โดยขึ้นกับบทบาทและสถานะปัจจุบัน

ศัพท์เฉพาะที่ควรรู้

ศัพท์ ความหมาย
งานหลัก (Parent Job) งานที่มีไฟล์ส่งมอบหลายชิ้น หรือมีงานย่อยแขวนอยู่
งานย่อย (Child Job) งานที่ขึ้นอยู่กับงานหลัก ต้องรองานหลักเสร็จก่อน
งานเดี่ยว (Standalone) งานธรรมดาที่ไม่มีความสัมพันธ์กับงานอื่น
SLA Service Level Agreement — ระยะเวลาที่กำหนดให้งานเสร็จ
BUD Business Unit Division — หน่วยงานย่อยที่สั่งงาน
เส้นทางการอนุมัติ ลำดับขั้นผู้อนุมัติที่งานต้องผ่านก่อนเริ่มทำ
