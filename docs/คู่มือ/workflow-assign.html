🟢 Flow 3: มอบหมายผู้รับงาน

ผู้อนุมัติ (Approver) หรือผู้ดูแลระบบ (Admin) กำหนดให้ Assignee (Designer/Developer) รับงาน

📊 Swimlane Diagram

sequenceDiagram actor A as Approver/Admin participant UI as UI System participant DB as Database participant Notify as Notification A->>UI: เข้า Job Detail page (status: approved) UI-->>A: แสดง "Assign Assignee" section A->>UI: เลือก Assignee จากลิสต์ (dropdown) UI->>DB: ตรวจสอบ assignee availability DB-->>UI: รายชื่อ assignees ที่พร้อมรับงาน A->>UI: เลือก 1 หรือ หลาย assignees A->>UI: (optional) ใส่ notes to assignees A->>UI: กดปุ่ม "Assign Job" UI->>DB: update assigned_to, status = "assigned" UI->>DB: บันทึก assignment record UI->>Notify: ส่งแจ้งเตือน Assignees Notify-->>Notify: Email: "New Job Assigned to You" DB-->>UI: บันทึก Activity Log UI-->>A: แสดงข้อความสำเร็จ

📋 รายละเอียด Flow

1

เข้าถึง Job Detail Page

  • Approver/Admin เปิด Job Detail ของงานที่ approved แล้ว
  • ระบบแสดง status = "approved" (พร้อมมอบหมาย)
  • ปุ่ม "Assign Assignee" ปรากฏเมื่อ status = approved
2

เลือก Assignee

  • Click "Assign Assignee" button
  • ระบบแสดง dropdown/modal พร้อมรายชื่อ available assignees
  • Filter ตามเกณฑ์:
    • User Role = Assignee
    • BUD = Job's BUD (หรือ assigned to BUD)
    • Project assignment (ถ้ามี)
    • Current workload (optional: ตัวเลือกซ่อน overloaded assignees)
  • สามารถเลือก 1 หรือหลาย assignees (parallel work)
3

เพิ่ม Assignment Notes (Optional)

  • Approver สามารถใส่ notes พิเศษสำหรับ assignees
  • เช่น: "Priority: High - Client meeting Friday"
  • Notes นี้ขึ้นไปที่ notification + Job detail
4

ยืนยัน Assignment

  • Click "Assign" button
  • ระบบ double-check:
    • ✓ Assignee เลือกแล้ว
    • ✓ Job type != null
    • ✓ SLA deadline > today
  • สร้าง assignment record พร้อม timestamp
5

ระบบประมวลผล

  • Update Job Status: approved → assigned
  • บันทึก Assignment: assigned_to_user_id(s) + timestamp
  • สร้าง Notification: ส่งไปยัง assignees ทั้งหมด
    • Email subject: "New Job Assigned: [Job Title]"
    • Link ไปยัง Job Detail page
    • แสดง Brief + Due Date + Assignment Notes
  • Activity Log: "Assigned to [Assignee Name] by [Approver]"

✅ Success Criteria

  • ✓ Job status เปลี่ยนเป็น "assigned"
  • ✓ assigned_to field เพิ่มขึ้น 1 หรือหลาย assignees
  • ✓ Notification sent ไปยัง assignees ทั้งหมด
  • ✓ Activity log บันทึก assignment action
  • ✓ SLA countdown เริ่ม (ถ้ายังไม่ได้)

⚠️ Multi-Assignee & Parallel Work

  • ระบบรองรับการมอบหมายให้หลาย assignees (e.g., Graphic Designer + Web Developer)
  • ทั้งหมดได้รับแจ้งเตือน และสามารถ start ได้อย่างอิสระ
  • Job ready completion เมื่อ ALL assignees นำเสนอ deliverables
