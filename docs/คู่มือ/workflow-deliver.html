🟢 Flow 5: ส่งมอบงาน (Complete)

ผู้รับงาน (Assignee) ส่งมอบงานพร้อมไฟล์ Deliverable และประเมิน SLA

📊 Swimlane Diagram

sequenceDiagram actor E as Assignee participant UI as UI System participant DB as Database participant Notify as Notification E->>UI: เข้า Job Detail (status: in_progress) UI-->>E: แสดง "Submit Deliverables" button E->>UI: กดปุ่ม "Submit Deliverables" UI-->>E: แสดง upload section E->>E: Prepare ไฟล์ output (PSD, PDF, design files) E->>UI: ลากไฟล์เข้า upload box UI->>UI: Validate ไฟล์ (size, type) E->>UI: เพิ่ม final comments/notes E->>UI: กดปุ่ม "Submit" ยืนยัน UI->>DB: update status = "completed" UI->>DB: บันทึก deliverables + completed_at UI->>DB: calculate actual_days vs SLA UI->>Notify: ส่งแจ้งเตือน Requester Notify-->>Notify: "Job Completed: [Title]" DB-->>UI: บันทึก Activity Log UI-->>E: แสดงข้อความสำเร็จ UI-->>E: Link ไปยัง "View Completed" หรือ Dashboard

📋 รายละเอียด Flow

1

เข้าถึง Job Detail (In Progress)

  • Assignee เข้า Job Detail ของงานที่กำลังทำ
  • Status = "in_progress" (blue badge)
  • ระบบแสดง "Submit Deliverables" button
  • แสดง SLA countdown + "Days Remaining"
2

เตรียมไฟล์ Deliverables

  • Assignee เตรียมไฟล์ finalized:
    • Design files (PSD, XD, Figma, SVG)
    • Export files (PNG, JPG, PDF)
    • Source code (HTML, CSS, JS ถ้า web)
    • Documentation / Specification
  • ตรวจสอบไฟล์ก่อนส่ง
3

อัปโหลด Deliverable Files

  • Assignee click "Submit Deliverables"
  • ระบบแสดง Upload Section:
    • Drag & Drop zone ด้านกลาง
    • Browse file button
    • Accepted file types: PDF, PSD, XD, Figma, PNG, JPG, ZIP ฯลฯ
    • Max file size: 50MB per file, 200MB total
  • Assignee อัปโหลด 1 หรือหลายไฟล์
  • ระบบ validate ขณะอัปโหลด (file type, size)
4

เพิ่ม Completion Notes (Optional)

  • Assignee สามารถเพิ่ม completion notes:
    • "All deliverables as per brief requirements"
    • "Design includes 3 variations as requested"
    • "Ready for review"
  • Support: @mention Requester/Approver
  • Notes ขึ้นไปในการแจ้งเตือน + Job history
5

ส่งมอบ (Submit)

  • Assignee กดปุ่ม "Submit Deliverables" ยืนยัน
  • ระบบแสดง confirmation:
    • "Confirm submission?"
    • "SLA Status: On Time / Warning / Overdue"
  • Confirm → ระบบประมวลผล
6

ระบบประมวลผล Completion

  • Update Job Status: in_progress → completed
  • บันทึก Completion Info:
    • completed_at = current time
    • completed_by = assignee name
    • actual_days_spent = (completed_at - start_at)
    • sla_status = "on_time" / "late" / (check if < due_date)
  • บันทึก Deliverables: ไฟล์ทั้งหมด → job_deliverables table
  • สร้าง Activity Log: "Completed by [Assignee]" + SLA status
  • ส่งแจ้งเตือน:
    • Requester: "Your job [Title] is complete!"
    • Include: deliverables link, download URL, completion notes
    • Approver (ถ้ามี final approval): "Job ready for review"

✅ Success Criteria

  • ✓ Job status เปลี่ยนเป็น "completed"
  • ✓ Deliverable files บันทึกลงระบบและ downloadable
  • ✓ SLA status คำนวณแล้ว (on_time / late)
  • ✓ Notification ส่งไปยัง Requester + Approver
  • ✓ Activity log บันทึก completion + SLA status

⚠️ SLA & Completion Status

  • On Time (🟢): completed_at ≤ due_date
  • Overdue (🔴): completed_at > due_date (แต่ยังคงให้ submit)
  • SLA violation ถูกบันทึกไว้สำหรับ analytics & metrics
  • ไม่ block job completion ไม่ว่า on time หรือ late

⚠️ Multi-Assignee Completion

  • ถ้า job assigned ให้หลาย assignees
  • แต่ละคนสามารถ submit deliverables เอกเทศได้
  • Job status เปลี่ยนเป็น completed เมื่อ ALL assignees submit
  • ระบบรวม deliverables จากทั้งหมด
