🔴 Flow 6: ปฏิเสธงาน (ผู้อนุมัติ)

ผู้อนุมัติ (Approver) ปฏิเสธงานในขั้นตอน pending_approval เพราะไม่ตรงตามเกณฑ์หรือข้อมูลไม่ชัดเจน

📊 Swimlane Diagram

sequenceDiagram actor A as Approver participant UI as UI System participant DB as Database participant Notify as Notification A->>UI: ดูรายการ Approvals Pending A->>UI: เลือก job ที่ต้องการปฏิเสธ UI-->>A: แสดง Job Details A->>A: ตรวจสอบและตัดสินใจปฏิเสธ A->>UI: กดปุ่ม "Reject" UI-->>A: แสดง rejection reason form A->>UI: ใส่เหตุผล (required) A->>UI: (optional) ใส่ instructions to resubmit A->>UI: กดปุ่ม "Confirm Rejection" UI->>DB: update status = "rejected" UI->>DB: บันทึก rejection_reason + rejection_by UI->>Notify: ส่งแจ้งเตือน Requester Notify-->>Notify: "Job Rejected: Please revise" DB-->>UI: บันทึก Activity Log UI-->>A: แสดงข้อความสำเร็จ UI-->>A: redirect ไป Approvals list

📋 รายละเอียด Flow

1

Approver ตรวจสอบ Job

  • Approver เข้า Job Detail ของงาน pending_approval
  • อ่านรายละเอียด brief, ไฟล์, และ comments
  • ตัดสินใจว่าจะปฏิเสธ (Reject) เพราะ:
    • Brief ไม่ชัดเจน
    • ขาดข้อมูลสำคัญ
    • ไม่ตรง scope หรือ budget
    • ต้องการปรึกษา stakeholder เพิ่มเติม
2

Reject Button & Form

  • Approver click "Reject" button
  • ระบบแสดง "Rejection Reason" form
  • Required fields:
    • Rejection reason (textarea)
    • Severity: Minor / Major (dropdown)
  • Optional fields:
    • Resubmit instructions (how to fix)
    • Requested changes (detailed list)
3

ใส่เหตุผลปฏิเสธ

  • Approver เขียนเหตุผล:
    • ✓ "Brief is too vague. Need specific target audience and design direction."
    • ✓ "Missing reference files. Please attach competitor design samples."
    • ✓ "Budget seems underestimated for this scope."
  • Severity: Minor (ฝึกหัด) vs Major (ต้องแก้ไขมาก)
  • Optional: ใส่ step-by-step instructions to resubmit
4

ยืนยันปฏิเสธ

  • Approver click "Confirm Rejection"
  • Confirmation dialog:
    • "Job will be returned to Requester"
    • "They will be able to edit and resubmit"
  • Confirm → ระบบประมวลผล
5

ระบบประมวลผล Rejection

  • Update Job Status: pending_approval → rejected
  • บันทึก Rejection Details:
    • rejection_reason = Approver's text
    • rejection_severity = Minor / Major
    • rejected_by = Approver name
    • rejected_at = current time
  • ส่งแจ้งเตือน Requester:
    • Email: "Your job [Title] has been rejected"
    • Include: Rejection reason + resubmit instructions
    • Link: Edit + Resubmit
  • Activity Log: "Rejected by [Approver] - [Reason]"

✅ Success Criteria

  • ✓ Job status เปลี่ยนเป็น "rejected"
  • ✓ Rejection record สร้างขึ้นมา (พร้อม reason + severity)
  • ✓ Notification sent ไปยัง Requester พร้อมเหตุผล
  • ✓ Requester สามารถ edit + resubmit
  • ✓ Activity log บันทึก rejection details

⚠️ Resubmission Process

  • Requester ได้รับแจ้งเตือนพร้อมเหตุผลปฏิเสธ
  • Click "Edit Job" → แก้ไข brief, ไฟล์, ฯลฯ
  • Click "Resubmit" → Job กลับไป pending_approval
  • Approver ตรวจสอบอีกครั้ง
