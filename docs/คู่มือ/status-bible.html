สถานะงานทั้งหมด (Status Bible)

ตารางนี้รวมสถานะงานทั้งหมดในระบบ พร้อมสี ความหมาย และว่าใครทำอะไรได้บ้าง

หมายเหตุ: สีในระบบจริงอาจแตกต่างเล็กน้อยตามธีม UI แต่ความหมายเหมือนกัน
สถานะ (ไทย) Status Code สี ความหมาย ใครเห็น
ร่าง draft 🔵 ฟ้า งานยังไม่ส่ง บันทึกฉบับร่างไว้ก่อน เฉพาะผู้สร้าง
ส่งแล้ว submitted 🔵 ฟ้า ส่งงานเข้าระบบ รอเข้าสู่ขั้นตอนอนุมัติ ผู้สั่งงาน + ผู้อนุมัติ
รออนุมัติ pending_approval 🟠 ส้ม อยู่ในคิวรอผู้อนุมัติพิจารณา ทุกคนที่เกี่ยวข้อง
อนุมัติแล้ว approved 🟢 เขียว ผ่านการอนุมัติ รอมอบหมายผู้รับงาน ทุกคน
มอบหมายแล้ว assigned 🔵 ฟ้า มีผู้รับงานแล้ว แต่ยังไม่เริ่มทำ ทุกคน
กำลังทำ in_progress 🔵 ฟ้า ผู้รับงานกำลังดำเนินการ ทุกคน
เสร็จสิ้น completed 🟢 เขียว งานเสร็จสมบูรณ์ มีไฟล์ส่งมอบ ทุกคน
ปฏิเสธ rejected 🔴 แดง งานถูกปฏิเสธโดยผู้อนุมัติหรือระบบ ทุกคน
รอผู้อนุมัติพิจารณา assignee_rejected 🟠 ส้ม ผู้รับงานขอปฏิเสธ รอผู้อนุมัติตัดสินใจ ทุกคน
ปฏิเสธโดยผู้รับงาน rejected_by_assignee 🔴 แดง ผู้อนุมัติอนุมัติให้ผู้รับงานปฏิเสธ ทุกคน

สรุปกลุ่มสถานะ

🟢 สถานะสำเร็จ (Terminal)
completed, rejected, rejected_by_assignee
งานจบแล้ว ไม่มีการเปลี่ยนแปลงอีก
🔵 สถานะกำลังดำเนินการ (Active)
draft → submitted → pending_approval → approved → assigned → in_progress
งานยังเคลื่อนไหวได้
🟠 สถานะรอดำเนินการ (Waiting)
pending_approval, assignee_rejected
รอคนอื่นตัดสินใจ

สิทธิ์ตามสถานะ

ตารางสรุปว่าแต่ละบทบาทสามารถทำอะไรได้ในสถานะต่างๆ

สถานะ ผู้สั่งงาน ผู้อนุมัติ ผู้รับงาน แอดมิน
draft แก้ไข, ส่ง, ลบ — — ดู, ลบ
pending_approval ดู, แสดงความเห็น อนุมัติ / ปฏิเสธ — ดู, แก้ไขได้บางส่วน
approved ดู มอบหมายผู้รับงาน — ดู, มอบหมาย
assigned / in_progress ดู, แสดงความเห็น ดู, แสดงความเห็น เริ่มงาน / ส่งมอบ / ปฏิเสธ ดู
completed ดู, ดาวน์โหลด ดู, ดาวน์โหลด ดู, ดาวน์โหลด ดู, ดาวน์โหลด
rejected / rejected_by_assignee ดู, สร้างใหม่ ดู ดู ดู, ลบ
