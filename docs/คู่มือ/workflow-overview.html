📊 User Flow ทั้งหมด

ระบบ DJ System มี 12 User Flow หลัก แบ่งออกเป็น 4 หมวดหมู่ตามประเภทของการทำงาน

✅ Happy Path Session (Single Flow)

เส้นทางเดียวสำหรับคนเริ่มต้น ตั้งแต่เปิดงานจนปิดงานแบบไม่ซับซ้อน

H

Happy Path: เปิดงานถึงปิดงาน

ผู้เปิดงาน -> ผู้อนุมัติ -> ผู้รับงาน -> Draft ตรวจ -> Final -> ปิดงาน

pending_approval -> assigned -> draft_review -> in_progress -> completed

🟢 Happy Path - สร้าง → อนุมัติ → ส่งมอบ

ขั้นตอนการทำงานตามปกติโดยไม่มีการปฏิเสธ ประกอบด้วย 5 flows หลัก

1

สร้างและส่งงาน

Requester สร้างงานและส่งเข้าสู่ระบบ

⚡ → pending_approval
2

อนุมัติงาน

Approver อนุมัติขั้นตอนการทำงาน

pending_approval → approved
3

มอบหมายผู้รับงาน

Approver กำหนดให้ Assignee รับงาน

approved → assigned
4

เริ่มงาน

Assignee เริ่มทำงานอย่างเป็นทางการ

assigned → in_progress
5

ส่งมอบงาน

Assignee ส่งมอบงานพร้อมไฟล์ deliverable

in_progress → completed

🔴 Exception Flows - การปฏิเสธ & แก้ไข

ขั้นตอนเมื่อการปฏิเสธเกิดขึ้น สามารถปฏิเสธในหลายจุดของกระบวนการ

6

ปฏิเสธงาน (ผู้อนุมัติ)

Approver ปฏิเสธงานในขั้นตอน pending_approval

pending_approval → rejected
7

ขอปฏิเสธงาน

Assignee ขออนุญาตปฏิเสธงานที่ได้รับมอบหมาย

assigned/in_progress → assignee_rejected
8

อนุมัติการปฏิเสธ

Approver ยินยอมให้ Assignee ปฏิเสธงาน

assignee_rejected → rejected_by_assignee
9

ไม่อนุมัติการปฏิเสธ

Approver บังคับให้ Assignee ทำงานต่อ

assignee_rejected → assigned (ทำต่อ)

🟡 Advanced Flows - ขั้นสูง

ฟีเจอร์ขั้นสูงสำหรับจัดการงานที่ซับซ้อน

10

ขยายเวลา SLA

Assignee ขอขยายเวลาส่งมอบเมื่อ SLA ใกล้หมดเวลา

assigned/in_progress → extension pending
11

Job Chaining (Parent/Child)

ระบบอัตโนมัติเปิด job ลูกเมื่อ job แม่เสร็จสิ้น

parent: completed → child: submitted
12

Magic Link Actions

สิทธิในการกระทำผ่านลิงก์อีเมล (approve/reject/view)

No status change, direct action

📌 เลือก Flow ที่คุณสนใจ

  • Happy Path (1-5): เหมาะสำหรับการเข้าใจขั้นตอนปกติ
  • Exception Flows (6-9): เพื่อรู้วิธีการจัดการปัญหาเมื่อต้องปฏิเสธ
  • Advanced (10-12): สำหรับเคสพิเศษ SLA, job chaining, และ email actions
