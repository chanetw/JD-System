🔧 แก้ไขปัญหาเบื้องต้น

แนวทางแก้ไขปัญหาที่พบบ่อยในระบบ ก่อนติดต่อแอดมิน

🔴 หน้าเว็บไม่โหลด / ขาว

1

รีเฟรชหน้าเว็บ

กด F5 หรือ Ctrl + R (Windows) / Cmd + R (Mac)

2

ล้างแคชและคุกกี้

กด Ctrl + Shift + R เพื่อโหลดแบบไม่ใช้แคช

3

ตรวจสอบการเชื่อมต่ออินเทอร์เน็ต

ลองเปิดเว็บไซต์อื่น เช่น google.com

4

ลองใช้เบราว์เซอร์อื่น

Chrome, Firefox, Safari, Edge

🟡 ข้อมูลไม่อัปเดต / ไม่ตรง

สาเหตุ: ข้อมูลในเบราว์เซอร์เก่า หรือการเชื่อมต่อ Socket.io ขาดหาย

วิธีแก้:

  • รีเฟรชหน้าเว็บ (F5)
  • ออกจากระบบแล้วเข้าใหม่
  • ตรวจสอบว่าไม่ได้เปิดหลายแท็บซ้อนกัน

🟠 ไม่ได้รับการแจ้งเตือน

สาเหตุ: การตั้งค่าการแจ้งเตือนถูกปิด หรือเบราว์เซอร์บล็อก

วิธีแก้:

  • ตรวจสอบการตั้งค่าการแจ้งเตือนในโปรไฟล์
  • อนุญาตการแจ้งเตือนจากเบราว์เซอร์ (เมื่อมีข้อความถาม)
  • ตรวจสอบโฟลเดอร์ Spam/Junk ในอีเมล

🔵 ปุ่มกดไม่ได้ / หายไป

สาเหตุ: สิทธิ์ไม่พอ หรือสถานะงานไม่ตรงเงื่อนไข

วิธีแก้:

  • ตรวจสอบบทบาทของคุณ (ดูที่มุมขวาบน)
  • ตรวจสอบสถานะปัจจุบันของงาน
  • รีเฟรชหน้าเว็บเพื่ออัปเดตสถานะล่าสุด

ติดต่อแอดมิน

หากลองทุกวิธีแล้วยังไม่ได้ กรุณาติดต่อแอดมินพร้อมระบุ

  • ชื่อผู้ใช้ / อีเมล
  • เบราว์เซอร์และเวอร์ชัน (เช่น Chrome 120)
  • ขั้นตอนที่ทำก่อนเกิดปัญหา
  • ข้อความ Error (ถ้ามี)
  • ภาพหน้าจอ (Screenshot)
