⚙️ คู่มือผู้ดูแลระบบ (Admin)

บทบาท: Admin

ผู้ดูแลระบบมีสิทธิ์สูงสุดในการจัดการข้อมูลพื้นฐานและตั้งค่าระบบ

สิ่งที่คุณทำได้

  • จัดการประเภทงาน (Job Types) + SLA
  • จัดการเส้นทางการอนุมัติ (Approval Flows)
  • จัดการผู้ใช้และบทบาท (User Management)
  • ตั้งค่าวันหยุด (Holidays)
  • จัดการ BUD และโครงการ
  • ดูรายงานและสถิติ (Analytics)
  • ดู Audit Logs

เมนูการจัดการ

เมนู ใช้ทำอะไร ความถี่
ประเภทงาน สร้าง/แก้ไขประเภทงาน และกำหนด SLA (วันทำการ) เมื่อมีประเภทงานใหม่
เส้นทางอนุมัติ กำหนดลำดับผู้อนุมัติสำหรับแต่ละประเภทงาน เมื่อมีการเปลี่ยนแปลงโครงสร้าง
ผู้ใช้งาน เพิ่ม/แก้ไข/ปิดใช้งานบัญชีผู้ใช้ เมื่อมีพนักงานใหม่/ลาออก
วันหยุด ตั้งค่าวันหยุดประจำปี (มีผลต่อการคำนวณ SLA) ปีละครั้ง หรือเมื่อมีวันหยุดพิเศษ
BUD / โครงการ จัดการหน่วยงานและโครงการที่ใช้สั่งงาน ตามความจำเป็น

การตั้งค่า SLA สำหรับประเภทงาน

1

เข้าเมนู "ประเภทงาน"

เลือกจาก Sidebar → Admin → ประเภทงาน

2

กด "เพิ่มประเภทงาน" หรือแก้ไขที่มีอยู่

กรอกชื่อประเภทงาน และจำนวนวันทำการที่กำหนด (SLA)

3

บันทึก

ระบบจะใช้ SLA นี้คำนวณกำหนดส่งมอบอัตโนมัติ

สำคัญ: การเปลี่ยน SLA จะมีผลกับงานใหม่เท่านั้น งานเก่ายังใช้ SLA เดิม

การตั้งค่าวันหยุด

วันหยุดที่ตั้งค่าไว้จะถูกข้ามเมื่อระบบคำนวณ SLA อัตโนมัติ

  • เพิ่มวันหยุดประจำปี (ขึ้นปีใหม่, สงกรานต์, แรงงาน, ฯลฯ)
  • เพิ่มวันหยุดพิเศษ (วันหยุดชดเชย, วันพระราชพิธี)
  • สามารถนำเข้าวันหยุดเป็นชุดได้
